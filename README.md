# AI Photobooth

A real-time AI photobooth built using Python, OpenCV and MediaPipe.

## Features
- Gesture-based photo capture
- Spacebar capture
- Face filters (glasses, crown, mustache)
- Photostrip generation with white border
- Event frame overlay
- Timestamp on photos

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy

## How to Run
1. Install requirements
2. Run: python photobooth_final.py
